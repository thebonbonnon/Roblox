# Roblox 5v5 MOBA

A complete, code-only 5v5 MOBA for Roblox, written in Luau. You don't need any assets. The map, towers, minions, bots and UI are all generated by scripts.

## Features

- **5v5 teams** (Blue vs Red). Players are auto-balanced, and empty slots are filled with **AI bot heroes** that lane, last-hit, trade, use abilities, respect tower range, retreat to heal and buy items. A bot steps aside when a player joins.
- **Three-lane map** (Top / Mid / Bot) with a river, jungle trees, bases and fountains.
- **Towers**: 2 per lane per team. An inner tower can't be damaged until the outer tower in its lane falls. Towers target minions first and switch to any enemy hero that attacks one of your heroes.
- **Nexus**: can be damaged once any of its team's inner towers is down. Destroy it to win. A new match starts automatically.
- **Minion waves** every 30s: melee, caster and siege minions that fight their way down each lane.
- **5 heroes**, each with Q/W/E/R abilities (skillshots, area spells, dashes, buffs, an execute). Includes stuns and slows.
  | Hero | Role | Q | W | E | R |
  |---|---|---|---|---|---|
  | Knight | Fighter | Cleave | Rally | Charge | Judgment |
  | Mage | Mage | Fireball | Frost Nova | Blink | Meteor |
  | Ranger | Marksman | Piercing Arrow | Volley | Tumble | Rain of Arrows |
  | Guardian | Tank | Shield Bash | Fortify | Ground Slam | Earthquake |
  | Assassin | Assassin | Shadow Strike | Smoke Veil | Poison Blade | Execute |
- **Progression**: XP and levels (max 15, ultimate unlocks at 6), gold from last hits, kills, assists, towers and a passive income.
- **Shop**: 9 items. You can buy at your fountain or while dead. Max 6 items.
- **Fountain**: heals allies quickly and shoots enemies who come in (stops spawn camping).
- **HUD**: hero select, ability bar with cooldowns and tooltips, HP/mana/XP, gold, K/D/A, team kill score, match clock, kill feed, minimap, Tab scoreboard, floating damage numbers.

## Controls

| Input | Action |
|---|---|
| Right-click ground | Move (hold to steer) |
| Right-click enemy | Auto-attack / chase |
| Q W E R | Cast ability toward the mouse |
| S | Stop |
| B | Shop |
| Tab (hold) | Scoreboard |
| Mouse wheel / Space | Zoom / reset zoom |

## Setup

This project uses [Rojo](https://rojo.space).

1. Install Rojo (e.g. `aftman add rojo-rbx/rojo` or `cargo install rojo`) and the Rojo plugin for Roblox Studio.
2. **Option A: live sync.** Run `rojo serve` in this folder, open a new Baseplate in Studio, and click *Connect* in the Rojo plugin.
   **Option B: build a place file.** Run `rojo build -o Moba.rbxlx` and open `Moba.rbxlx` in Studio.
3. Delete the default `Baseplate` / `SpawnLocation` if they exist (the map is generated at runtime).
4. Press **Play**. To test teams, use *Test → Clients and Servers* with several players.
5. Before publishing, set **Max Players = 10** in Game Settings.

## Project layout

```
src/
  shared/          -> ReplicatedStorage.Shared
    Config.lua       tuning values (gold, XP, waves, stats)
    Heroes.lua       hero + ability definitions (add heroes here)
    Items.lua        shop items
    MapData.lua      lane paths, tower/base positions
  server/          -> ServerScriptService.Server
    Main.server.lua  match flow, teams, bots fill, remotes
    Units.lua        unit registry, damage, buffs, health bars
    HeroService.lua  hero stats, leveling, gold, respawn, shop
    Abilities.lua    ability execution (skillshot/aoe/dash/buff/execute)
    Minions.lua      wave spawning + lane AI
    Structures.lua   towers + nexus
    Bots.lua         AI heroes
    MapBuilder.lua   procedural map
    Effects.lua      visual effects
    Net.lua          RemoteEvents
  client/          -> StarterPlayerScripts.Client
    Main.client.lua  camera, input, click-to-move
    HUD.lua          all UI
```

## Adding a hero

Add an entry to `Heroes.Defs` in `src/shared/Heroes.lua` and append its id to `Heroes.Order`. Abilities are data-driven. Combine the existing types (`skillshot`, `aoe`, `selfaoe`, `dash`, `buff`, `execute`) with fields like `damage`, `stun`, `slow`, `pierce`, `count`/`spread`, `delay`. To add a new ability type, add an executor in `src/server/Abilities.lua`.

## Notes / next steps

- The server is authoritative for all health, damage, cooldowns, gold and shop purchases. Clients only send intents (move target, cast at point, buy).
- Minions and bots are anchored parts moved by the server, which is cheap and predictable. On a laggy connection their movement can look a bit choppy. Moving those visuals to the client would make it smoother.
- Ideas: jungle camps, more heroes and items, recall (B-to-base), fog of war, ranked matchmaking with a lobby place and `TeleportService`.
